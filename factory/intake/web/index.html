How It Works

1. Start a voice conversation (or type your idea). Describe the feature you need.

2. Answer clarifying questions. I'll ask about actors, acceptance criteria, constraints, etc.

3. Review the draft issue. It auto-updates as we talk. Edit if needed.

4. File the issue. It goes to your project repo and is immediately ready for the factory to claim and implement.

All conversations are stored so you can resume later. Gemini's API key is never exposed to your browser.
